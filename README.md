# Proyecto 1 - Recorrido del Caballo

## Descripción

Este proyecto implementa distintas soluciones para el problema del recorrido del caballo en un tablero de ajedrez.

El sistema permite:
- Resolver el recorrido completo del caballo
- Trabajar con obstáculos dentro del tablero
- Contar caminos posibles usando programación dinámica
- Utilizar la heurística de Warnsdorff para optimizar el recorrido
- Visualizar el tablero y las estadísticas del algoritmo

## Algoritmos implementados

### Backtracking
Implementación base del recorrido del caballo utilizando retroceso para probar diferentes caminos posibles.

### Programación dinámica
Implementación para calcular cuántos caminos distintos existen entre dos posiciones usando exactamente `k` movimientos.

### Heurística de Warnsdorff
Versión optimizada que ordena los movimientos  según la cantidad de movimientos futuros disponibles.
